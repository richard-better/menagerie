# Agent notes

- Layout: `macos/` is the macOS 27 SwiftPM app. `MenagerieCore` owns fleet parsing, polling, Git, deployment, cancellation, Ghostty screen snapshots, and PTY supervision; `Menagerie` owns SwiftUI views, the AppKit status item, and the CoreText terminal grid. The Rust workspace keeps `crates/agent`, `crates/protocol`, and `crates/fleet`.
- Before a clean Swift build, run `mise install` and `scripts/build-ghostty`. It builds the pinned static library and PTY launcher into ignored `target/ghostty/`. Check Swift with `swift test --package-path macos` and `swift format lint --strict --recursive macos/Sources macos/Tests macos/Package.swift`. Check Rust with `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, and `cargo test --workspace`.
- Build the signed app with `scripts/bundle` using Xcode 27.2 or newer. `scripts/bundle --notarize` retains the notarytool profile flow. The executable accepts `--show-window` and `--show-popover` for real-app inspection. Use `screencapture` for screenshots. Expand the menu bar manager behind the « item before testing status-item anchoring. Terminal test mappings and opt-in administrator checks are in `macos/TESTING.md`.
- Exercise sync and commit against temporary repositories with `MENAGERIE_FLEET` pointing to a disposable fleet, using a `custom` sync command. Keep the owner's running app and real configuration checkout untouched by deployment tests.
- `macos/Sources/Menagerie/Views.swift` holds the palette. Colour carries meaning: green healthy or charging, amber needs attention, sage the primary action. Service letter icons retain their brand colours.
- Authorization Services runs only the rebuild as root, with a pipe-watching wrapper to cancel its process group. Git runs as the user. Preserve commit-only flake URLs, literal pathspecs, symlink-safe reads, secret filtering, and bounded terminal input/output when changing these paths.
- The original design plan is `docs/plans/master-plan-v1.html`; it contains historical Rust and deployment decisions. Current source is authoritative. Historical UI judging rounds are in `.ui-judge/`.
